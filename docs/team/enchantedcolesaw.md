### Project: TAssist

TAssist is a desktop app for CS2040S teaching assistants to track tutorial attendance, class participation, and
assignment submissions.

Given below are my contributions to the project.

* **Code contributed**: [RepoSense link][reposense]

* **Features and enhancements**:
  * Command registration and shared argument validation.
  * Tutorial-group creation, listing, and switching, and weekly attendance marking and listing.
  * Save-status feedback, rollback after failed saves, and protection against overwriting unreadable data.
  * Student search and sorting, and student-row clicks that prepare attendance commands.
  * The Records workspace for readable listings and keyboard scrolling.

* **Documentation**: the corresponding UG instructions, DG implementation details and manual tests, and updates
  to the persistence sequence and UI class diagrams.

* **Testing and team contributions**: unit, integration, and JavaFX tests for these features, including persistence
  and failure recovery. Reviewed teammates' PRs covering data protection, student-view preservation, and attendance
  statuses ([#186][pr186], [#241][pr241], [#306][pr306]).
